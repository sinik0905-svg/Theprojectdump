# Task Manager
# JavaScript Daily Practice

This repository contains my daily JavaScript practice as I learn the language step by step.

Instead of creating a new project for every topic, I am building and improving a **Task Manager** by adding new features as I learn new JavaScript concepts.

- Validate empty input
- Simple and responsive UI using HTML and CSS
